## GitHub Pages

GitHub Pages is a **static site hosting service** that allows users to host a website directly from a GitHub repository. It takes HTML, CSS, and JavaScript files from your repository, optionally runs them through a build process, and publishes the content as a website.

### Who Can Use GitHub Pages?

| Plan/Repository Type | Availability |
| :--- | :--- |
| **GitHub Free** (Public Repositories) | Available |
| **GitHub Pro, Team, Enterprise Cloud/Server** (Public & Private Repositories) | Available |

### Types of GitHub Pages Sites

There are two primary types of GitHub Pages sites, each with specific requirements for their source files and location:

| Property | **User and Organization Sites** | **Project Sites** |
| :--- | :--- | :--- |
| **Source Files** | Must be stored in a repository named `<owner>.github.io`, where `<owner>` is the account name. | Stored in a folder within the repository that contains the project's code. |
| **Limits** | Maximum of **one** Pages site per account. | Maximum of **one** Pages site per repository. |
| **Default Location** | `http(s)://<owner>.github.io` | `http(s)://<owner>.github.io/<repositoryname>` |

### Custom Domains

You have the flexibility to host your site on GitHub's default `github.io` domain or configure your own **custom domain** for the site.

### Data Collection

For security purposes, when a GitHub Pages site is visited, the visitor's **IP address is logged and stored**, even if the visitor is not signed into GitHub.
